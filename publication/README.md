This folder contains the supplementary data of the associated manuscript:

## Contents
- `Table_S1_clean_occurrences_per_sampling_regime.xlsx`: .xlsx file containing the list of species used, and the associated growth form
- `Table_S2_Updates_to_Beierkuhnlein_2021.xlsx`: .xlsx file containing the specific changes that were made to the flora published by [Beierkuhnlein et al. (2021)](https://www.mdpi.com/1424-2818/13/10/480)
- `Table_S3_environmental_dataset_balanced_aggregate.csv`: .csv file containing data of aggregated environmental data using a balanced sampling regime
- `Table_S4_plant_image_references.xlsx`: .xlsx file containing references for the used (plant) images in the manuscript
